隐私

只处理 必要数据

我们不为广告、画像或转售而采集数据。为完成账户、路由、计费与安全防护，只处理这些功能所必需的数据；具体范围以隐私政策为准。

  • 仅处理账户、路由、计费与安全所必需的数据。
  • 不保存提示词、回复正文等 API 请求内容。
  • 不出售用户数据。
  • PokeAPI 不将用户数据用于模型训练。
